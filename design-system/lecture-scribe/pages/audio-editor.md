# Audio Editor Page Override

- This is a dedicated dark studio, not a light modal form.
- Left/main region: tool strip, precision time control, zoom, waveform, playback.
- Right inspector: automatic detection, selected region actions, excluded-region list.
- Waveform `#8073F1`; cut `#F2A84B`; excluded fill `rgba(205,54,63,.44)`; selection `#42D7D0`; playhead `#FF5DA2`.
- Keep click-to-cut, V/C/P shortcuts, typed time seek, wheel zoom, Shift+wheel pan, and playback buttons.
- Every colour in the legend has a text label.
- Excluded items use a two-line format so precise time values remain readable in the inspector.
